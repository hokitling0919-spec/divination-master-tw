# Divination Master TW 繁體占卜師
一套開源、使用**正體中文(繁體)** 的占卜工具套件。
支援靈籤抽籤、易經起卦、塔羅占卜，適合開發機器人、本地占卜程式。

## 📌 專案特色
✅ 全部資料使用繁體中文，適合臺灣、港澳使用
✅ 純文字資料庫，可自由編輯籤詩、解釋文
✅ 模組化架構，容易擴充 LINE Bot / Web 介面
✅ 隨機公平抽籤演算法，可自訂吉凶標籤

## 📦 環境需求
- Python 3.9+
